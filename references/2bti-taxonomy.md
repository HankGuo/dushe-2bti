# 2BTI 人格坐标系 v3 — 16 型

> 自创人格坐标系。对标 MBTI：**4 条轴 × 2 个极 = 16 种类型**。
> 每型有：中文名 + 英文名 + 一句话人设 + 毒舌金句 + 专属配色。
> **代码与文档中不出现任何人名。**

---

## 一、四条轴

### 轴 1：`B / P` — 能不能造出东西
| 极 | 含义 | 判定 |
|---|---|---|
| **B** = Build | 能把想法变成可运行的东西 | `f(落地力, 架构脑) ≥ 60` |
| **P** = Paper | 停留在方案、文档、构想层面 | 否则 |

### 轴 2：`R / T` — 干事的姿态
| 极 | 含义 | 判定 |
|---|---|---|
| **R** = Rogue | 横冲直撞、推倒了再来、边骂边干 | `f(探索欲, 构想力) ≥ 60` |
| **T** = Tame | 可控、可复现、有方法论、稳 | 否则 |

### 轴 3：`S / D` — 驱动力来源
| 极 | 含义 | 判定 |
|---|---|---|
| **S** = Spark | 外部点燃——被需求、面子、他人期待推着走 | `f(社交电量, 抗压值) ≥ 55` |
| **D** = Drive | 内部驱动——自己想做，不做会难受 | 否则 |

### 轴 4：`L / F` — 对待不确定性的态度
| 极 | 含义 | 判定 |
|---|---|---|
| **L** = Lock | 要锁定——讨厌悬而未决，必须有结论 | `f(抗压值, 落地力) ≥ 60` |
| **F** = Flow | 随波随流——接受没结论，享受过程 | 否则 |

> **四轴两两组合 → 16 型。** 编号规则：`轴1轴2` 决定大族，`轴3轴4` 决定细分性格。

## 三、四族视觉语言（不可省）

前两位决定**大族**，大族决定**视觉语言**。只换配色 = 同一张卡的 16 个变量，用户一眼看穿。
四层差异必须同时存在：

| 族 | 主题 | 背景纹理 `pattern` | 卡片质感 | 雷达填充 `radar` | 徽章形状 |
|---|---|---|---|---|---|
| **BR** 能造×野 | **施工现场** | `hazard` 斜向警示条纹 | 3px 粗边 + 8px 硬阴影 | `stripe` 斜纹 | 圆角方牌 |
| **BT** 能造×稳 | **工程蓝图** | `blueprint` 细网格 + 十字准线 | 1px 细边 + 内发光 | `gradient` 渐变 | 小圆角方牌 |
| **PR** 纸上×野 | **舞台聚光** | `spotlight` 顶部聚光锥 | 2px 双线 + 大圆角 | `soft` 柔和径向 | 粗描边圆牌 |
| **PT** 纸上×稳 | **公文档案** | `ledger` 横线稿纸 + 装订线 | 直角 + 轻投影 | `cross` 交叉斜线 | 双线方牌 |

**实现位置**：`render.py` 的 `FAMILIES` 字典 + HTML 模板里的 `body.fam-XX` CSS 块 + 雷达图的 `RADAR_STYLE` 分支。

完整表见 `render.py` 的 `TYPE_GLYPHS`。

**为什么徽章要加底板**：深色符号（♟👁🕯🗂）在深色底上等于没渲染——
实测徽章区彩色像素仅 5 个。底板 = 径向高光 + 主色渐变 + 白描边 + 内阴影 + 虚线外环，
形状随族变。加底板后亮度占比提升到 12%~76%。

深色符号**不要带变体选择符**（`♟️` → 用 `♟`），否则部分平台回退成文字模式。

## 五、六维雷达（0-100）

| 维度 | 键名 | 低分 | 高分 | 毒舌解读 |
|---|---|---|---|---|
| 构想力 | `ideate` | 只执行不自己想 | 点子一个接一个 | "脑子里已经上市了" |
| 落地力 | `exec` | 只说不做 | 说干就干真做出来 | "PPT 冠军 / 交付怪物" |
| 架构脑 | `arch` | 混沌流 | 结构清晰 | "硬盘是空的，脑子是满的" |
| 探索欲 | `curio` | 守着自己那摊 | 到处挖 | "新工具装了一堆，正事没动" |
| 抗压值 | `tough` | 一点就炸 | 骂完继续干 | "被骂完还能接着派活" |
| 社交电量 | `social` | 社恐 | 到哪都能聊 | "见人先热场然后后悔" |

**分数要有区分度**——真实人格是参差的。全 80+ 的图等于没测。
**形状要有故事**——尖角多 = 偏科；全圆 = 平庸。

## 七、词云标签池

词条要**具体、可截图、能被本人认领**。优先三类：

- **行为标签**：`基建狂魔` `纸上架构师` `方案永动机` `嘴上说算了`
- **反差标签**：`嘴上嫌弃实际在用` `写完就跑` `骂完继续干`
- **梗标签**：`给AI写刑法` `两套Agent同时养` `10秒后又回来问`

**反例**（不要用）：`优秀` `勤奋` `聪明` `有魄力`——抽象形容词没有传播力。

## 八、目标名来源（不硬编码）

4. 环境变量 `HOSTNAME`
5. 兜底：`路人甲`

## 十、象限计算（可直接编码）

```python
def classify(dims):
    d = dims
    bp = (d["exec"] + d["arch"]) / 2      # ≥60 → B
    rt = (d["curio"] + d["ideate"]) / 2   # ≥60 → R
    sd = (d["social"] + d["tough"]) / 2   # ≥55 → S
    lf = (d["tough"] + d["exec"]) / 2     # ≥60 → L
    return (f"{'B' if bp >= 60 else 'P'}{'R' if rt >= 60 else 'T'}"
            f"-{'S' if sd >= 55 else 'D'}{'L' if lf >= 60 else 'F'}")
```

**16 型可达**——只要六维分数有区分度，四轴组合自然分散。

## 十一、开源注意

- 渲染产物是**单个自包含 HTML**，零外部请求、离线可看
- 词云是自研 Canvas sprite-mask 布局算法，非商用词云库，无版权问题
- 字体走系统栈，不内嵌字体文件
- 坐标系为本项目原创，可自由署名使用
- **示例数据必须是虚构人物**，不得包含真实用户的账号、路径、硬件信息
